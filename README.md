Entry for the make.fun bounty **"How Many Tabs Do You Have Open?"** — one honest
number: the count of browser tabs open right now. The most surprising count wins.

This entry answers **87**: odd, specific and non-round, high enough to surprise,
yet still a number a real tab hoarder could honestly have open across a couple
of windows.

## Run it

```sh
node main.ts
```

It writes the single number `87` (digits only, no trailing newline) to
`/output/entry.txt`.
